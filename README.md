# CryptoRal

CryptoRal is a simple ERC20 token built with [OpenZeppelin](https://openzeppelin.com/contracts/).  
The contract automatically mints **1000 tokens (18 decimals)** to the deployer's wallet when deployed.

You can see the transaction searching 0x64f99a665297b23a6b1ff76cb6166fc088cd8144d1b2223f5bb385ad15ab0ed5 on [Arbiscan.io](https://arbiscan.io/) or clicking on the following link [Transaction](https://arbiscan.io/tx/0x64f99a665297b23a6b1ff76cb6166fc088cd8144d1b2223f5bb385ad15ab0ed5)

## ⚡ Important
This project is designed to be used **exclusively with [Remix IDE](https://remix.ethereum.org/)**, not VSCode if you want to it, you should import OpenZeppelin  
If you try to run it outside of Remix, the import from OpenZeppelin will not work unless you manually install the library.
